# Projects using Vanilla JS
Here is a list of 5 projects using only HTML , CSS and JavaScript.
## 1. BMI
A simple JavaScript-based BMI Calculator that takes height and weight as input.
Calculates BMI and displays the corresponding category: Underweight, Normal, or Overweight.
Built using HTML, CSS, and JavaScript with basic form validation and DOM manipulation.

## 2. DigitalClock
A simple digital clock built using HTML, CSS, and JavaScript.
Displays the current date and time using JavaScript's Date object.
The clock updates automatically every second using setInterval().

## 3. InfiniteColors
A simple JavaScript project that dynamically changes the webpage background to random colors.
Generates random hexadecimal color codes and applies them every second.
Includes Start and Stop buttons to control the automatic color-changing interval.

## 4. NumberGuessing
A simple JavaScript number guessing game where players try to guess a randomly generated number between 1 and 100.
The game provides hints for guesses that are too high or too low and tracks previous guesses and remaining attempts.
Includes a restart option to generate a new number and start a fresh game.

## 5. ColorSwitch
A simple JavaScript project that changes the webpage background color when a color button is clicked.
Uses DOM selection and event listeners to handle user interactions.
Includes multiple color options such as grey, purple, blue, yellow, and green.

## Conclusion

This repository contains five mini Vanilla JavaScript projects: **BMI Calculator, Digital Clock, Random Color Generator, Number Guessing Game, and Color Switcher**.
Each project focuses on practical JavaScript concepts such as DOM manipulation, event handling, form validation, timers, random number generation, and dynamic styling.
These projects demonstrate my hands-on practice with Vanilla JavaScript and serve as a foundation for building more interactive web applications.
